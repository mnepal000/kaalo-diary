# कालो डायरी

नागरिक निगरानी (वाचडग) पोर्टल — बालेन्द्र शाह नेतृत्वको सरकारका विवाद, अनियमितता र
जवाफदेहिताका प्रश्नहरूको तथ्य, मिति र स्रोतसहितको दस्तावेजीकरण।

प्रेरणा: २७ जेठ २०८३ मा प्रतिनिधिसभामा नेपाली कांग्रेस संसदीय दलका नेता भीष्मराज
आङ्देम्बेले जिकिर गरेको 'कालो डायरी' अभियान।

## संरचना

- `index.html` — मुख्य पेज (नेपाली मात्र)
- `styles.css` — डिजाइन (डार्क 'डायरी' थिम)
- `data.js` — सबै प्रविष्टिहरू (ENTRIES array)
- `app.js` — खोज, फिल्टर, मोडल लजिक

## नयाँ प्रविष्टि थप्ने

`data.js` मा `ENTRIES` array मा नयाँ object थप्नुहोस्:

```js
{
  id: "kd-012",
  dateBS: "असोज २०८३",
  dateAD: "अक्टोबर २०२६",
  title: "...",
  category: "...",   // संसदीय मर्यादा | कानुनी शासन | सुशासन | मानवअधिकार | परराष्ट्र / राष्ट्रियता
  status: "...",     // विपक्षीको आरोप | समाचारमा आएको | पुष्टि भएको | छानबिनमा | खण्डन भएको
  summary: "...",    // छोटो सारांश
  details: "...",    // पूरा विवरण
  sources: [ { label: "...", url: "https://..." } ],
  tags: ["..."]
}
```

## स्थानीय परीक्षण

```bash
cd ~/workspace/kaalo-diary
python3 -m http.server 8000
# http://localhost:8000 खोल्नुहोस्
```
